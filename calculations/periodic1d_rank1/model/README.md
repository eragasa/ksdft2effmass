# Periodic-1D rank-one model protocol

This calculation-owned surface records the scientific construction and evaluation
protocol for periodic one-dimensional rank-one Bloch-hopping models.

The canonical LaTeX source is [`protocol/protocol.tex`](protocol/protocol.tex). It uses
the ordinary-lattice displacement--Bloch-momentum pair \(R\)--\(k\), binds the lattice
kinetic-energy scale \(E_a=\hbar^2/(m_ea^2)\) without a factor \(1/2\), requires physical
energy units and exact scalar Hermiticity, and separates finite-cyclic Fourier
coefficients from ordinary-lattice hoppings.

The protocol defines contracts and claim boundaries. It does not authorize external
calculation, seal evidence, or establish material validation.
