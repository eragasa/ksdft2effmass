# Bain-path replaceable analysis

This tree owns replaceable analysis outputs for the separate M0, M1/M2, and sampled scan
actions:

- `results/` — M0 geometry/frozen-gauge records;
- `response/` — separately labeled M1 and M2 records and plots;
- `scan/` — base-grid, qualification, envelope, and transition records and plots.

Generated JSON, PDF, and PNG products are intentionally excluded from source integration.
They are not retained execution evidence, convergence, a common path witness, or a
material result.
