# Bounded periodic-3D M0 geometry control

This directory receives the replaceable canonical M0 result from
[`run_geometry_control.py`](../../../run_geometry_control.py). M0 holds the flat parent
and reduced-coordinate gauge fixed while the unit-volume Bain metric changes, so its
locality outcome is geometry/frozen-gauge response only.

Schema validation, Parseval agreement, and finite sampled shell decisions establish
bounded software behavior. They do not establish convergence, a material response, a
phase transition, or retained evidence.
