# Comprehensive band-edge figures, version 3

This immutable rendering is the strict-typing successor to version 2. It uses the same
retained `result.json`, `multiband-result.json`, and `plot-data.json` and makes the same
layout-only changes: separated legends/titles and increased conduction-panel spacing.
No Hamiltonian, valley search, Hessian, mass tensor, or multiband fit was recomputed.
