  support removal;
- C6 construction-mesh use for reconstruction only and 408-point development-inventory
  use for full-source-relative hopping characterization;
- separate descriptive Pareto frontiers for support cost versus each operator, ordered-
  spectrum, gap, valley, curvature, and mass metric, without scalarization or selection;
- explicit separation of gauge-fixed hopping matrices from unsupported atomic-orbital,
  sigma, or pi semantics;
- separate parent-to-source, spatial-truncation, parameterization, and end-to-end error
  channels;
- preservation of S105's full-support disposition, `H_T = H_W`, unless a new prospective
  support study is separately admitted;

  channel errors;
- revealed 408-point parent comparisons displayed only as development evaluation
  overlays that cannot change candidates, frontiers, support, fits, or thresholds;
- a confirmation-only 402-point boundary that forbids using its geometry or future
  values to define diagnostics, candidates, frontiers, truncation, fitting, thresholds,
  or numerical policy;
- preservation of the 108/108 split exclusively for a future separately authorized
  Slater--Koster study;
- freezing hopping results, reductions, diagnostic rules, fits, and evaluation
  definitions before any confirmation comparison; and
- separately authorized continuation after the hopping-first synthesis: spectral-only
  feasibility, a global-unitary rank-10 operator study, a separately defined rank-9
  projected source, or a new Slater--Koster-compatible Wannier source. The reusable
  Level-1 Slater--Koster foundation remains synthetic software evidence only.

TB-anchored alignment contract. The rank loss is documented as an orbital-subspace
overlap failure rather than an established consequence of energy degeneracy. The
fail-closed diagnostic sequence, projector/symmetry approach, global-unitary rank-10
branch, and new-source branch are specified in the
[common-space rank-deficiency diagnosis and successor proposal](../analysis/c6-b20-w21-slater-koster-definition-fit/common-space-rank-deficiency-diagnosis-and-successor.md).
That proposal does not activate a continuation stage or authorize an external
calculation. Level 1 reusable foundations have been
[implemented with synthetic software verification only](../analysis/c6-b20-w21-slater-koster-definition-fit/level-1-foundation-disposition.md);
this does not close the HF0--HF4 hopping gates, activate Level 2, or produce a reduction.
The ladder is not an automatic workflow. Spectral-only work cannot claim an operator
residual, rank-9 work introduces a distinct target-space error, a new Wannier source
requires fresh bounded calculator authorizations and its own hopping-first analysis,
and singular-value regularization is limited to labeled sensitivity analysis.

No protocol file authorizes a calculator invocation.
