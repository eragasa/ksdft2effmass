# Development analysis outputs

`development/generated/` is the replaceable output location for the bounded cross-protocol
composition defined by the experiment-owned
[`comparison-protocol.md`](../../../experiments/model-adequacy/band-equivalence-dimensional-comparison/comparison-protocol.md).

The dimensional-comparison PNG and PDF files are generated by
[`../plot_development.py`](../plot_development.py). The eight case-resolved
shell--scale landscapes and their four-case principal composite are generated by
[`../plot_shell_scale_decision_landscapes.py`](../plot_shell_scale_decision_landscapes.py).
The latter samples every available complete shell and 17 comparison scales on the path
from the restricted-alignment optimum to unity. Its surfaces connect adjacent calculated
cells only; they do not establish continuum frontiers or acceptance regions. The same
entry point writes canonical source-request, decision-request, result, and verification
JSON for each family. Strict packaged schemas, SHA-256 source/request binding,
environment identifiers, and exact read-back checks qualify artifact mechanics only.

These outputs are not retained evidence and must not be interpreted as scientific
acceptance or convergence results. Generated files remain outside integration commits
unless a later review explicitly defines and authorizes their evidence role.
