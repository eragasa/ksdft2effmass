# Hopping-locality channel

This channel owns descriptive real-space hopping powers, tails, and range diagnostics
for the represented rank-two operators along the rhombic path. Translation indices are
interpreted through the path's physical direct-lattice metric.

Hopping locality does not delete support and does not choose an admissible truncation.
Those irreversible decisions belong to [`support_truncation/`](../support_truncation/README.md).
