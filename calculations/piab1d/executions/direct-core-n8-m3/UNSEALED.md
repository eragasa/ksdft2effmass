It was generated from KSD commit
`6f03395120823859bd581d60efdfcd107b939aef`, which pins PhysKit commit
`9c74ffa2fa0f40792117ccaa6c0bf0bcb0e70fe5`.

The execution is intentionally unsealed. `development-provenance.json` records its
source revision, dependencies, reproduction commands, and artifact identities. The
execution has no seal, execution-wide checksum catalog, source manifest, sealed
provenance record, or evidence-package identity. It is retained as development output
for inspection and does not constitute sealed evidence, scientific validation,
publication acceptance, or a software release.
