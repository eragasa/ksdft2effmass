# Retained research-protocol figures

These figures are immutable version-one calculation-local visualizations of already
retained JSON records. They perform no accepted-parent, operator-producing, Quantum
ESPRESSO, Wannier90, remote, or protected execution. The pre-qualification and post-qualification recommendation atlases are retained
separately under `../figures-v2/` and `../figures-v3/`; these files are not overwritten.

- `folding-null-residuals.{pdf,png}` is derived from
  `executions/folding-null-controls-v1/results/result.json`, authenticated as SHA-256
  `8c771b58a135f4ea16412cfbaa825efa9ab1d26f0365a83de10d1d4af1d9b44c`.
  It shows dimensionless synthetic residuals relative to the prospective `1e-11`
  criterion.
- `finite-domain-inventory.{pdf,png}` is derived from
  `executions/finite-domain-defect-planning-v2/results/case-inventory.json`,
  authenticated as SHA-256
  `da722ec9042b232162c46fe49e228c14c714665cae35f6043e475d3d3d9a88d5`.
  It shows the added `1x1` through `5x5` small-cell aliasing controls and planning
  counts only; all 3,240 proposed operator evaluations remain unexecuted.

`../render_research_protocol_figures.py` owns deterministic rendering and no-overwrite
behavior. The LaTeX research protocol retains these PDF variants and embeds the
current version-three atlas from `../figures-v3/`.
