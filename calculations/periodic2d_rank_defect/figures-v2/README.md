# Protocol figure atlas, version 2 (preserved)

These PDF and PNG pairs are deterministic renderings produced by
`../render_research_protocol_figures.py`. The renderer authenticates the retained
Folding and Null-Alignment Controls result and version-2 finite-domain planning
inventory before rendering and refuses to overwrite any output.

Evidence classes:

- **retained numerical evidence**: `folding-null-residuals` and
  `folding-null-metric-atlas` use the authenticated authored folding/null result;
- **execution-free planning inventory**: `finite-domain-inventory` and
  `evaluation-accounting` use the authenticated unexecuted 3,240-evaluation inventory;
- **frozen planning geometry**: `parent-support-collisions`,
  `parent-support-equivalence-maps`, `radius-two-core-equivalence-maps`,
  `boundary-twist-mesh`, and `shape-orientation-gallery` visualize declared integer
  supports and case geometry only; and
- **oracle planning diagram**: `seam-oracle-phases` displays the analytically expected
  phase convention without claiming a new operator or oracle execution.

None of these figures contains defect spectra, eigenstates, binding energies,
localization diagnostics, finite-size convergence, material validation, uncertainty
quantification, or evidence that the 3,240 proposed defect evaluations occurred.
Version 1 under `../figures/` remains immutable. The post-qualification atlas is
retained separately under `../figures-v3/`; this directory is not overwritten.
