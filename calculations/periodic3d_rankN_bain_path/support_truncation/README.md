# Prospective support-truncation capability

This directory reserves irreversible support selection for the periodic-3D rank-N Bain
context. The geometry subprotocol selects the metric and basis-aware distance but does
not select support. A future protocol must define complete conjugate-closed
physical-metric shells, equal-radius tie handling, common versus pointwise support, the
shell cap or complete ladder, minimum-support and unresolved outcomes, and retained-block
counts. It must use the unit and displacement convention in
[`../geometry-common-state-space.md`](../geometry-common-state-space.md).

M0 and M1N may report changed metric shell membership or physical radii only after such
a policy is selected; their frozen common-coordinate Fourier coefficients do not by
themselves select a cutoff or retained-block count.

Withheld interpolation is evaluated before support removal. Truncation-only consequences
compare against the complete interpolant; total consequences compare against the direct
withheld field. These channels are not added, and descriptive hopping power does not
select support. No truncation action or result is owned here.
