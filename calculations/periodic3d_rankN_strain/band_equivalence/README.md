# Prospective band-equivalence capability

This directory reserves comparisons of explicitly aligned periodic-3D rank-N represented
operators and ordered spectra along the Bain path. The common cell/state map, ordered
`2r` fiber, reduced-coordinate convention, direct-length unit, and geometry are selected
in [`../geometry-common-state-space.md`](../geometry-common-state-space.md). Before any
subtraction, the full protocol must additionally identify the retained basis, gauge,
energy unit, energy reference, reciprocal sample inventory, admitted band-subspace rank,
and normalization scale for the compared channel.

For M0, the selected flat `lambda=0` shared-`2r` parent and attacked retained field have
exact same-strain representation equivalence and zero cross-strain common-coordinate
response; [`../m0-geometry-only-control.md`](../m0-geometry-only-control.md) owns those
operands without selecting a fitted alignment. For M1N, the selected common-coordinate
parent and attacked represented field are likewise frozen along the path; its exact
aligned operator response is zero. Any nonzero M0 or M1N path response is a
numerical/state-identification diagnostic. Withheld-interpolation,
truncation-only, and total consequences require different operands and remain separate.
A fixed-geometry rank-N equivalence result and a rank-two Bain outcome provide no
cross-rank or cross-path evidence. No comparison action or result is owned here.
