evidence conventions with the rank-two and higher-rank calculations.

This report is a pre-execution design note.  No scalar model coefficients, calculation

package exists.  The document does not authorize execution or evidence promotion.

\section{Rank-one structural boundary}

Let $H(k)\in\mathbb{C}$ be a scalar represented Hamiltonian and let
$U(k)\in U(1)$.  Scalar multiplication commutes, so
\begin{equation}
  U(k)^\dagger H(k)U(k)=H(k)\,U(k)^\dagger U(k)=H(k).
\end{equation}
Consequently, an internal phase cannot redistribute a scalar represented Hamiltonian
among Fourier hopping blocks.  The rank-one calculation can test scalar interpolation
and truncation, but it cannot exhibit the gauge-induced represented-operator locality
that becomes possible at rank two and above.

This algebraic observation determines the null-control role.  It does not select the
future numerical model and is not itself a finite-mesh result.

\section{Alignment-channel applicability}

Only the no-alignment scalar channel is scientifically distinct.  One-global-phase,
pointwise-phase, known-inverse-phase, and restricted internal-rotation channels are
operator-identical in rank one.  They must be recorded as inapplicable as distinct
alignment channels rather than emitted as duplicated numerical results.
