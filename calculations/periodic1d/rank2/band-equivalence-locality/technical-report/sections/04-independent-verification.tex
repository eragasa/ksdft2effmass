\section{Independent verification}

The maintained verifier reconstructs harmonic maximization, frame alignment, raw block
powers, and selected observables without trusting producer diagnostics.  Verification
must check parent Hermiticity, retained-space isolation, frame orthonormality, reciprocal
closure, projector reconstruction, pointwise spectral equivalence, Parseval identities,
and range-selection decisions.

For the flat family, finite-mesh correlation and the analytic $J_0(2a)$ comparator are
distinct fields.  Agreement between them is a convergence diagnostic, not permission to
replace finite data with the analytic value.  For the dispersive family, shared parent
eigenvalues and projectors supply frame-invariant refinement channels.  Neighbor-overlap
singular values are qualification gates rather than convergence observables.

No independent verification result is presently owned by this successor directory.
