# Quantum ESPRESSO hydrogen-molecule SCF backend

**Status: planned; no execution selected or authorized.**

No project-owned QE input or pseudopotential has been selected for the H$_2$ learning
objective. This directory intentionally contains no fabricated input, expected value,
or runtime output.

A future implementation must define its own cell, boundary-condition, pseudopotential,
functional, cutoff, sampling, convergence, and output-processing choices. It must not
reuse the ABINIT calculated values as QE expectations. Any numerical comparison would
require a separate alignment contract and execution authorization.
