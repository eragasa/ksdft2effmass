# ABINIT nickel collinear spin bands

**Status:** correspondence placeholder only; no implementation or execution is authorized.

A future ABINIT realization would require an independently specified and licensed
pseudopotential, explicit collinear-spin and occupation conventions, a compatible FCC
band path, and separately authorized execution. It must not treat the Quantum ESPRESSO
pseudopotential, magnetization, band indices, or numerical values as a cross-backend
oracle.
