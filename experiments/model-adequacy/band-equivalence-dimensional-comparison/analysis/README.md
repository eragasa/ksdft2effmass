# Development analysis outputs

`development/` is the replaceable output location for the bounded cross-protocol
composition defined by [`../comparison-protocol.md`](../comparison-protocol.md).

The PNG and PDF files are generated by [`../plot_development.py`](../plot_development.py).
They are not retained evidence and must not be interpreted as scientific acceptance or
convergence results. Generated files remain outside integration commits unless a later
review explicitly defines and authorizes their evidence role.
