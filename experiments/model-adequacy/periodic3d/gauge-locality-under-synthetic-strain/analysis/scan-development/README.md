# Sampled 3-D Bain strain scan

This directory receives replaceable 201-point development plots from
[`../../scan_development.py`](../../scan_development.py). The scan reports sampled
witness-requirement envelopes, geometry-only locality costs, the frozen-parent null
response, and the prescribed radial response. It is not a continuum certificate,
convergence result, retained evidence package, or material-strain calculation.
