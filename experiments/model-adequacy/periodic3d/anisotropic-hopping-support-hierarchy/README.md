# Periodic 3-D anisotropic hopping-support hierarchy

## Status

This directory preserves the publication-independent home for the later anisotropic
three-dimensional admissible-set experiment family:

```text
ksdft2effmass.campaign.model-adequacy.periodic3d.anisotropic-hopping-support-hierarchy
```

The human-owned sequence is `isotropic 2-D -> isotropic 3-D -> anisotropic 2-D ->
anisotropic 3-D`. This directory owns the fourth stage, not the first 3-D implementation.
Its mirrored [architecture package](../../../../docs/architecture/v2/experiments/model-adequacy/periodic3d/anisotropic-hopping-support-hierarchy/index.md)
separates science, numerics, implementation, and schematics documentation.
The exact orthorhombic scalar parent and candidate freeze controls are preserved in
[protocol.md](protocol.md); the disclosed exploratory threshold calculation remains
separate in [threshold-design.md](threshold-design.md). Advance design work does not
bypass the selected sequence. No immutable `.v1` identity, implementation, schema,
retained run, or evidence package exists.

The experiment is deliberately anisotropic. It tests three-dimensional representation,
support nesting, witness, and certificate semantics without assuming simple-cubic axis
permutations, diamond-lattice shell equivalence, a silicon Wannier basis, or material
validity. Bulk silicon remains a separate material-reference experiment family.

## Ownership boundary

The eventual experiment will own its exact synthetic parent, lattice convention,
support classes, objective-construction and evaluation roles, thresholds, coefficient
domain, metric,
certificate premises, strict schemas, independent verifier, retained evidence policy,
and interpretation. Reusable finite-periodic transforms or unit-free numerical kernels
may be consumed from their reviewed owners; they do not own the scientific composition.

No installed package may import this experiment tree. Nothing here authorizes Quantum
ESPRESSO, Wannier90, remote, cluster, or production execution.

## Current gate

Implementation remains deferred until the earlier isotropic 3-D and anisotropic 2-D
stages have isolated their respective architecture stresses. Before this family can
receive `.v1`, review and freeze its protocol, implementation dependency identities,
strict input/result schemas, independent exact-rational verification route, tests, and
evidence-retention policy. Any exploratory threshold calculation must remain identified
as design work and separated from the later sealed evaluation.
