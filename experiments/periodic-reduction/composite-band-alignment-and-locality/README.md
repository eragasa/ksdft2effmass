# Composite-band alignment and locality experiments

This family-first directory groups dimension-specific maintained experiments involving
composite retained spaces, alignment, and gauge-dependent locality. It is an
organizational container, not itself an experiment identity.

## Maintained dimensions

- [`periodic1d/`](periodic1d/) — prospective publication-independent successor for the
  historical rank-two alignment and locality calculations.

Additional dimensional children require their own reviewed scientific contracts and are
not implied by this layout.
