# PIAB2D rectangular-box diagnostics

## Status

**Prospective protocol.** No immutable experiment version, retained run, or numerical
evidence exists.

The initial tranche is restricted to a homogeneous-Dirichlet rectangular domain with
orthogonal Cartesian axes. Oblique direct bases, generalized eigenproblems, and
non-orthogonal representation bases are separate later work.

See [`protocol.md`](protocol.md) for the scientific and ownership boundary. A retained
calculation directory must not be created until the protocol, schemas, resource bounds,
verifier identity, and evidence policy are frozen and execution is authorized where
required.
