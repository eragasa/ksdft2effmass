# Authored paper packages

This directory contains publication-planning records and manuscript packages. The
`Ragasa2026a`--`Ragasa2026g` directories are the canonical, identity-based locations for
the seven-paper working sequence associated with ICMSEP 2026. Each identity contains
explicit `vN/` source versions; no directory name asserts submission, acceptance, or
publication.
