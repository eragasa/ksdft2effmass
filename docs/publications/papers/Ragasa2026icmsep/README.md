# Ragasa2026icmsep

Long-form working synthesis of the exact rank-two band-equivalence/locality framework and the completed rank-10 silicon Wannier reduction program.

This package is new and does not overwrite:

- `Ragasa2026a`, which remains the focused rank-two theory paper;
- `Ragasa2026d`, which remains the provenance-oriented silicon plan/status manuscript; or
- the historical `ICMSEP2026/optional-paper`, which is superseded archival material.

The synthesis is intentionally longer than a conventional conference paper. It combines analytic theory, controlled numerical evidence, material-derived development calculations, detailed limitations, and appendices containing the calculation inventory, algorithmic specification, error ownership, checksums, and claim boundaries.

No submission, publication, release, or authorship decision is implied by this directory.
