\chapter{Candidate Contemporary Literature for Later Review}
\label{app:candidate-contemporary-literature}
\index{citation!prospective literature register}
\index{literature review!candidate sources}

\chapterstatus{prospective literature register. The records below preserve the
human-supplied candidate set, with identifier-level metadata corrections where
primary publisher, repository, or official project pages were checked. Except
where another appendix explicitly says that a paper was read, presence here
means neither that the source has been read nor that its proposed manuscript
claim has been accepted.}

This appendix is a review queue, not a literature synthesis. A bibliography
record allows a candidate citation to render; it does not establish that the
source supports the proposed local claim. Before any citation is moved into a
main chapter, the source must be read and checked against the exact sentence.
Software websites are retained as secondary operational references rather than
substitutes for archival papers. Placeholder identifiers are not entered in the
bibliography.

The status phrases used below have the following meanings.

\begin{description}
  \item[Metadata checked.] The DOI or canonical record resolved and its core
    bibliographic fields were checked. The article itself remains unread unless
    stated elsewhere.
  \item[Official link checked.] The official documentation, project, repository,
    or proceedings page resolved, but it may change over time.
  \item[Existing record.] The bibliography already contained the source before
    this review queue was added.
  \item[Correction required.] The supplied author, year, venue, title, or
    identifier did not match the resolved record.
  \item[Unresolved.] The supplied record contains a placeholder or lacks enough
    verified metadata to create an authoritative bibliography entry.
\end{description}

\section{Review disposition}

No candidate in this appendix should be inserted mechanically. Later review
should record, for each proposed use, the exact manuscript sentence, the source
passage that supports it, and whether the claim is about software capability,
mathematical structure, numerical verification, scientific validation, or
uncertainty quantification. Unresolved records require corrected primary
metadata before source review begins.
