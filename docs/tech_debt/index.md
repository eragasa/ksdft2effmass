# Technical debt

This section records bounded, nonblocking software follow-ups that are safe to defer.
It is maintained narrative documentation, not an executable task system, workflow
engine, release gate, or authorization record. Repository architecture,
specifications, source contracts, tests, and retained provenance remain authoritative
for their respective subjects.

## Recorded topics

- [Conditioning-diagnostic expansion](conditioning-expansion/index.md)
- [Post-init validation structure](post-init-validation-structure/index.md)

A technical-debt record does not weaken a current blocking review finding or imply
that deferred work is scientifically validated, uncertainty quantified, accepted, or
authorized for execution.
