# Task 08.03.03: Select the minimal boron model

## Status

`Blocked`

## Objective

Select the minimal boron model. The task produces the artifact BMinimalModel-v1 required by the downstream dependency graph.

## Prerequisites

[[ksdft2Effmass.computational.08.03.02|08.03.02]].

Each prerequisite must be represented by its accepted versioned artifact and validation record.

## Inputs

- a validated atomistic impurity operator or synthetic benchmark;
- the common reduction engine and model-class definitions;
- the acceptance vector defined in `ksdft2Effmass.computational.08`;
- every versioned artifact supplied by the prerequisites.

## Procedure

1. Construct the requested model class from the frozen atomistic operator.
2. Record exactly which matrix elements, ranges, orbital structures, or parameters are retained.
3. Solve the reduced Hamiltonian using the common eigensolver and state-matching procedure.
4. Compute the complete acceptance vector against the atomistic reference.
5. Store the reduced operator, complexity record, errors, and model-selection decision.

## Outputs

Primary output:

`BMinimalModel-v1`

The output must be accompanied by its input manifest, software and environment record, validation results, and sufficient metadata to identify its state space, basis, geometry, and energy convention where applicable.

## Acceptance Criteria

- the reduced model is generated by a reproducible rule;
- all model levels use identical state matching and validation definitions;
- acceptance or rejection follows the prespecified error vector rather than visual agreement;
- the declared output exists and can be reconstructed from the stored inputs;
- all task-specific numerical tolerances are recorded with a pass/fail result;
- unresolved failures are not propagated as accepted downstream inputs.
