# Computational Task Template

## Status

`Blocked`, `Ready`, `Active`, `Review`, `Passed`, `Failed`, or `Deferred`

## Objective

State one computational result produced by this task.

## Prerequisites

List prerequisite task identifiers or gates. Each prerequisite must resolve to a versioned artifact and passing validation record.

## Inputs

List:

- physical and numerical specifications;
- datasets;
- operator or model records;
- software and environment requirements.

## Procedure

Provide an executable sequence of calculations or implementation steps.

## Outputs

List persistent artifacts, filenames, schemas, figures, and tables.

## Acceptance Criteria

State numerical pass/fail conditions. Avoid criteria based only on visual inspection.

## Validation

Record:

$$
\text{reference},
\qquad
\text{candidate},
\qquad
\text{metric},
\qquad
\text{tolerance},
\qquad
\text{result}.
$$

## Unlocks

List downstream task identifiers made ready when this task passes.

## Failure and Recovery

State the likely failure modes and which inputs, assumptions, or model classes may be revised without silently changing the research question.
