# Agentic development case study

This directory contains machine-readable and human-readable records for a
prospective longitudinal embedded case study of human-governed,
specification-first agentic development in scientific software.

The study records how repository control-plane decisions, public specifications,
validation fixtures, tests, documentation, integration review, and human
checkpoints interact during development of `ksdft2effmass`. It does not treat AI
agent output as reviewed science and does not use passing software checks as
scientific validation.

- `protocol.md` defines the study protocol.
- `research-questions.md` records research questions and propositions.
- `case-register.json` indexes episodes.
- `instruments/` contains schemas and classification instruments.
- `episodes/` contains episode records and evidence indexes.

Episode `E00` is a retrospective pilot reconstructed from repository evidence.
Episode `E01` is the first prospective episode and covers Graphify integration.
Episode `E02` prospectively records the accepted operator-record validation
correction and progressive VVUQ evidence migration.
