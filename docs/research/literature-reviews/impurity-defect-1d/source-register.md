## Access failures retained

- The DTIC route for the Koster--Slater paper returned HTTP 403. Detailed claims
  were therefore not drawn from an assumed full text.
- Some Crossref metadata calls returned HTTP 429. Publisher and arXiv routes
  were used as the independent metadata checks where this occurred.
- The attempted Kohn--Luttinger download was HTML despite a `.pdf` suffix.
  Ghostscript reported `/syntaxerror in /----nostringval----`; the file was not
  used as a PDF.
- `pdftoppm` was unavailable during one image-conversion attempt, and one OCR
  command exited 127. These tool failures did not upgrade any source's access
  classification.
- Google blocked some late exact-phrase searches with an unusual-traffic page.
  Those blocked queries were not counted as evidence that no matching source
  exists.
