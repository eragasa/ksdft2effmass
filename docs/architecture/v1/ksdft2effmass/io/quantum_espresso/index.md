# `ksdft2effmass.io.quantum_espresso` package in v1

The Quantum ESPRESSO namespace contains the implemented QEXSD boundary. It does
not expose an input renderer, executor, stream parser, general `.save` parser,
or calculator registry.

- [`ksdft2effmass.io.quantum_espresso.qexsd`](qexsd/index.md) — exact source-byte
  records, mechanical XML parsing, and bounded semantic construction.

Direct `pw.x` execution is calculation-owned and documented separately under
[repository-level calculations](../../../calculations/index.md).
