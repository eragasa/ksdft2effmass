# `RetrievedEvidenceExcerpt`

`RetrievedEvidenceExcerpt` is one frozen source-linked projection. It retains Search
evidence-item, ranked-item, and one-based rank identities; References projection-item,
bibliographic-work, closed status, and active canonical-key state; Ingestion selection,
transcript, selected-page, selected-block, page, block, and block-record identities;
clean indexed text and digest; retained raw quotation text and digest; exact-pair
mapping basis; ordered source spans; and warning codes. Candidate proposed keys are
never represented as canonical. Its derived `excerpt_id` binds every represented
value.
