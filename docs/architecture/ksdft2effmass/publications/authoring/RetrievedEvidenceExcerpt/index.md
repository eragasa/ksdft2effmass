# `RetrievedEvidenceExcerpt`

`RetrievedEvidenceExcerpt` is one frozen source-linked projection from external
retrieval and citation-identity resolution. It retains external evidence and
bibliographic-work identities, the exact closed citation status, a canonical citekey
only for active accepted status, ingestion selection/transcript/page/block record IDs,
clean indexed text and digest, retained raw quotation text and digest, exact-pair
mapping basis, ordered source-span IDs, and warning codes. Candidate proposed keys are
deliberately not represented as canonical. Its derived `excerpt_id` binds every
represented value.
