# `ManuscriptAuthoringIssue`

`ManuscriptAuthoringIssue` is the deterministic detailed failure vocabulary. Its
declaration order is the canonical tuple order used by `ManuscriptAuthoringResult`.
It separates retrieval shortfalls, warnings, stale revisions, output limits, inference
correlation, evidence identity, evidence-marker consistency, citation consistency, and
citation gaps that require inspection without discarding a bounded draft.
