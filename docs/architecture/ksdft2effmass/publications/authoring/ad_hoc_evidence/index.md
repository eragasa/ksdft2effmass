# `ksdft2effmass.publications.authoring.ad_hoc_evidence`

This module owns immutable evidence and projection records for the separately
identified author-supplied ad-hoc path. It represents only the three explicitly
authorized APS publisher abstract pages and never represents full-paper review,
rights determination, scientific acceptance, or human acceptance.
