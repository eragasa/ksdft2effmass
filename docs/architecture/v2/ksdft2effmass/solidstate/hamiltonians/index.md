# `solidstate/hamiltonians`

## Responsibility

This package owns finite represented and effective Hamiltonian constructions. It does
not own crystal structures, native-file decoding, calculation execution, retained-space
selection, convergence, or physical acceptance.

Python implementation: `ksdft2effmass.solid_state.hamiltonians`.

Package initializers reserve exports for reviewed composite facades; concrete records
and Actions remain in their owning submodules.
