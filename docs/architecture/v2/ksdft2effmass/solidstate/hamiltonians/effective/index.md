# `solidstate/hamiltonians/effective`

## Responsibility

This package groups explicitly named finite selected-space effective-Hamiltonian
families. It does not collapse retention, basis selection, reduction, evaluation,
directional contraction, or mass interpretation into one generic workflow.

Python implementation: `ksdft2effmass.solid_state.hamiltonians.effective`.
