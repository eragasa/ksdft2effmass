# Periodic architecture migration archives

This page indexes completed migration records that no longer belong in the active
architecture tree. Git stores each immutable completed record; this page stores only
its status, repository locator, and links to the final authoritative architecture.
It does not duplicate archived document contents.

A repository locator has the form:

```text
<commit>:<repository-relative-path>
```

It can be inspected with `git show <commit>:<repository-relative-path>`.
