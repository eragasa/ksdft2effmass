# `periodic1d.campaign.model` target mapping

## Purpose and status

The current source remains temporarily under the legacy underscored campaign namespace.
This target mapping does not endorse `model` as its final canonical subpackage name.
The transitional source retains campaign-local reusable definitions while phase 5
moves demonstrated scientific parents, retention objects, and represented operators to
canonical owners. Its path does not classify every contained record as a scientific
model.

demonstrated. Encoded documents and campaign policy remain separate. Source and tests
