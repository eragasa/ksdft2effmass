# Reduction-challenge verification contract

## Verified channels

The independent verifier reconstructs all retained values used by its disposition:

- plane-wave amplitude sweep observables;
- potential-shape spectra and symmetry/shift diagnostics;
- complete mesh/band/isolation Cartesian-product observations;
- deterministic gauge-covariance projector, aligned transported-frame, and closure-
  holonomy diagnostics;
- complete uniform, incomplete-training, and nonuniformly weighted fitting-route
  diagnostics against the mediated hopping coefficients; and
- complete finite Fourier reconstruction values required by those channels.

The aggregate passes exactly when each of the five channel maxima is finite and less
than or equal to the supplied nonnegative finite unitless tolerance.

## Authentication and order

Verification first correlates exact supplied input/result bytes. The result-declared
input SHA-256 must equal the supplied input byte identity before any input-owned
scientific control is used. Correlation also checks experiment identity, ordered
potential/discretization inventories, explicit shape names and gap cardinalities, the
full amplitude/mesh/band Cartesian product, and route controls. No metadata is
inferred from a path, filename, digest, shape, rank, or spectrum.
