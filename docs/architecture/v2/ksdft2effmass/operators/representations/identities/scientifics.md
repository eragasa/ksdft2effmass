# Scientific interpretation

## Nodes and carriers

Bloch fields have momentum carrier `H: K -> End(V)` and use `BlochSpaceRole`.
Cell-hopping fields have translation carrier `H_hat: Gamma -> End(V)` and use
`CellHoppingRepresentationRole`. `RepresentationIdentity` composes the complete domain,
represented space, role, and source identity and rejects cross-family roles.

Gauge-conjugated, aligned, transformed, and reconstructed status is derivation history,
not an intrinsic node role. It belongs to directed identities and Actions under
`operators.transformations`.

## Evidence boundary

Node identities and enum members state intended semantics. They do not prove properties
of arrays, operator correctness, provenance truth, transformation correctness, numerical
qualification, or scientific validity.
