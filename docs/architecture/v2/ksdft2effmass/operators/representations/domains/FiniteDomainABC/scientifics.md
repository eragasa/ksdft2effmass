# Scientific interpretation

`FiniteDomainABC` represents the identity and cardinality of a finite index domain used
to correlate matrix values. It is deliberately agnostic about whether points represent
momenta, translations, parameters, or another future finite domain.

The interface does not assert that a domain samples a Brillouin zone completely, carries
a physical measure, respects inversion, approximates a continuum, or is suitable for a
scientific claim. Those meanings belong to concrete leaves and outward evidence.
