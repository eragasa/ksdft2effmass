# Scientific interpretation

A transformation is a typed directed relationship between explicit source and target
representation nodes. It is distinct from the underlying mathematical operator, either
finite representation, and evidence that an operation was valid or correctly executed.

The implemented kind inventory distinguishes frame compression, gauge conjugation,
alignment, finite Fourier conversion, support truncation, and Fourier reconstruction.
Frame compression `F† H F` is distinct from projector construction `F F†` and from
restriction to an invariant subspace.

Enum agreement across request, Action, result, and emitted edge identity is a nominal
computational contract only. It does not establish dimensional compatibility, unitarity,
Fourier inversion, support semantics, preservation laws, qualification, scientific
validity, or formal theorem correspondence.
