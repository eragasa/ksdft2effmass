# Scientific interpretation

The nominal skeleton represents a KSD-owned computational morphism interface between
identified representation nodes. It is separate from immutable `TransformationIdentity`
metadata and from Formal-owned mathematical relations or certificate predicates.

Enum agreement identifies only the operation family. It does not establish witness
validity, numerical correctness, qualification, evidence, or proof. Operation-specific
contracts must state spaces, bases, carrier domains, orientation, units, and failure
semantics.
