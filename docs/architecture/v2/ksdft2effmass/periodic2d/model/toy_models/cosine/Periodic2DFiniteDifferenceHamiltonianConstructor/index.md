# `Periodic2DFiniteDifferenceHamiltonianConstructor`

## Purpose and status

This implemented row-035 Action adapts one cosine parent and exact campaign request to
`FiniteDifferenceBlochHamiltonian2DConstructor`.

It samples the cosine potential on the unchanged period-`2*pi` half-open grid, composes
immutable unitless potential data, unit kinetic scale, Euclidean coordinate basis,
model energy zero, and explicit source/operator/state-space/provenance identities, then
delegates the only matrix assembly algorithm. The returned campaign result retains the
original request.

The adapter changes neither grid order nor Bloch-seam orientation and introduces no
compatibility alias. It performs no eigensolve, convergence assessment, common-space
comparison, or acceptance decision.
