# `ksdft2effmass.periodic2d.run.wannier90.optimizer_basin.standalone`

## Purpose

This package owns one repository-portable campaign for the retained standalone
periodic-2D Wannier90 optimizer study. It separates exact wire ownership, schema
adaptation, compact-source authentication, endpoint arithmetic, aggregate/basin
correlation, and orchestration into cohesive immutable records and instantiated Actions.

It is campaign-specific. It is not a generic optimizer framework, survival-analysis
framework, plugin point, native-artifact reader, or scientific acceptance mechanism.

## Retained bounded result

The compact result retains 256 completed initial localization processes over 16
configuration/optimizer groups and 16 deterministic starts. It records 136 initially
native-converged endpoints, 120 continuation attempts, 60 continuation convergence
statements, 196 effective native-converged endpoints, and 60 stopped nonconverged
endpoints. These counts and the group/basin summaries are reconstructed without opening
the declared external native run roots.

The exact retained disposition is **does not support the frozen standalone
finite-sequence criteria**. The package preserves that negative finite-design statement.
It does not prove that no convergence limit or global optimum exists.

## Ownership boundary

Proposal thresholds and deterministic-start identities are explicit retained design
controls. They are not inferred from filenames, endpoint order, numerical values, or
optimizer outcomes. The verifier authenticates only the four directly declared compact
repository sources in its frozen contract. Historical absolute path strings remain
report content, not filesystem authority.

Passing verification establishes bounded software and arithmetic consistency only. It
does not rerun Wannier90, authenticate the unavailable external native tree, validate
basin equivalence as a scientific oracle, establish optimizer completeness, quantify
physical uncertainty, or record acceptance.
