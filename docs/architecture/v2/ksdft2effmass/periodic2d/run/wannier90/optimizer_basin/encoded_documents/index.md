# Optimizer-basin encoded documents

This module owns one immutable exact-byte input/result container, not an initial-gauge
model, optimizer, basin classifier, native Wannier90 artifact group, convergence result,
numerical oracle, provenance record, or serializer.

## Classes

- [`Periodic2DOptimizerBasinEncodedDocuments`](Periodic2DOptimizerBasinEncodedDocuments/index.md)
  — exact input and result bytes for the retained optimizer-basin study.

## Boundary

Decoding belongs to explicit serialization owners; gauge construction, native-file
authentication, endpoint correlation, basin classification, independent numerical
reconstruction, convergence assessment, and scientific acceptance belong to dedicated
owners. No completed run, basin identity, global optimum, convergence result, or native
artifact is inferred from paths, filenames, hashes, encoded status strings, dimensions,
spectra, or labels.
