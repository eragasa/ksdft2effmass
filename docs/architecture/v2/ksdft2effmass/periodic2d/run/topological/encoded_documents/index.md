# Periodic-2D topological encoded documents

This module owns immutable exact-byte containers, not physical models, topological
invariants, scientific results, numerical oracles, or serializers.

## Classes

- [`Periodic2DTopologicalEncodedDocuments`](Periodic2DTopologicalEncodedDocuments/index.md)
  — exact input and result bytes for the retained topological campaign.

## Boundary

Decoding belongs to explicit serialization owners; topological construction,
comparison, and independent verification belong to dedicated scientific owners.
Repository location and evidence correlation belong to operation boundaries. No model,
topological, provenance, or acceptance meaning is inferred from paths, filenames,
hashes, shapes, dimensions, spectra, labels, or encoded expected observations.
