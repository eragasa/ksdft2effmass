# Periodic-2D composite encoded documents

This module owns immutable exact-byte containers, not scientific models, retained band
groups, frames, represented operators, or serializers.

## Classes

- [`Periodic2DCompositeEncodedDocuments`](Periodic2DCompositeEncodedDocuments/index.md)
  — exact input and result bytes for the retained composite campaign.

## Boundary

Decoding belongs to explicit serialization owners; scientific construction and retained
space adoption belong to dedicated Actions and results; repository location and
evidence correlation belong to operation boundaries. The encoded-document DataObject
infers no meaning from paths, filenames, hashes, shapes, dimensions, spectra, or group
identifiers.
