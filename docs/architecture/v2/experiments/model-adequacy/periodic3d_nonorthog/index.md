# Non-orthogonal periodic 3-D model-adequacy experiments

## Purpose

This subpackage mirrors experiment families with a non-orthogonal three-dimensional
primitive basis. It is deliberately separate from [`periodic3d`](../periodic3d/index.md)
so geometry, shell semantics, protocols, versions, resources, and evidence cannot be
inherited implicitly from orthogonal families.

## Child map

- [Silicon-inspired diamond-lattice band equivalence versus hopping locality](band-equivalence-versus-hopping-locality/index.md)

The child has a substantive protocol plus bounded, independently verified local
three-level matrix-free tensor actions with replaceable records. It has no immutable version,
retained run, or qualified result. Selection of one FCC primitive lattice does not establish a
general 3-D lattice API.
