# Numerical method

The finite parent acts on `(C^N)^(tensor 3) tensor C^4`; retained fields act on a
rank-two fiber. Batched tensor Fourier transforms connect cell, Bloch, and Wannier
coordinates. Parent lifting, full covariant alignment, and restricted global alignment
are distinct.

FCC cell-block shells use
`R_1^2 + R_2^2 + R_3^2 + R_1 R_2 + R_1 R_3 + R_2 R_3` and complete
integer-metric-group orbits. The inspired parent additionally reports entry distances
`|A(R + tau_beta - tau_alpha)|` so a cell radius is never mislabeled as an atomic bond
length. Its structure factor, four-state reconstruction, rank-two projector, and
continuous external-gap bound are independent verification targets. The comparator requires symmetric triple summation,
certified tail control, and independent torus quadrature. Interpolation, truncation, and
total matrix/spectral errors are evaluated on a shifted disjoint mesh. First-passing
shells require mesh stability or remain `unresolved`; all meshes require resource caps.
