# Anisotropic 3-D scientific method

## Parent model

The proposed parent is one spinless scalar orbital on an orthorhombic Bravais lattice
with a fixed real basis and zero onsite energy.

- Direct lengths are unequal and explicitly recorded in the source protocol.
- Reduced reciprocal coordinates define the Bloch phase convention.
- Time reversal is complex conjugation in the fixed scalar basis.
- The parent coefficients are exact binary fractions in electron volts.
- No Kohn–Sham, Wannier, silicon, orbital, valley, or spin interpretation is attached.

## Symmetry construction

The parent admits independent coordinate-sign changes but not axis permutations.

- A canonical representative has nonnegative integer coordinates.
- Its orbit contains distinct coordinatewise sign variants.
- Orbit multiplicity depends on the number of nonzero coordinates.
- Equal Euclidean radius does not merge different directional representatives.
- Hermitian closure is included by each sign orbit.

## Candidate hierarchy

The maximal parent inventory is reduced through four named support groups.

- Axial nearest support enters first.
- Face-diagonal support enters second.
- Body-diagonal support enters third.
- Axial second-neighbor support enters fourth.
- Every class remains embedded in one ten-coordinate maximal space.

## Adequacy question

The experiment asks for the smallest tested support class with one common spectral and
operator witness.

- The spectral channel uses a frozen weighted three-dimensional objective-construction
  mesh.
- The operator channel compares the complete maximal represented block domain.
- Smaller classes require emptiness or certified separation before minimality is claimed.
- Evaluation and locality observations cannot change the decisive result.
