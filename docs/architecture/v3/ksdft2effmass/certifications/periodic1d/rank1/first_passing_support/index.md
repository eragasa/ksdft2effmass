# Periodic-1D rank-one first-passing-support certification

## Implemented contract

This leaf implements the exact certification wire for the finite proposition that one
selected ordinary-lattice support is the first support jointly passing the mediated and
direct total-maximum error threshold.

The request binds the frozen controlled four-state parent, finite mesh inventories,
Fourier convention, candidate identities, threshold, selected support, repository tree,
source hashes, dependency lock, native result, and passing numerical-verification
artifact. The result binds all 32 support/objective intervals, producer and verifier
source identities, separately hashed artifacts, working precision, directed-rounding
policy, error budget, and exact disposition.
