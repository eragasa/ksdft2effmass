# Scientific interpretation

The comparator answers a bounded question: what is the signed finite-matrix difference
between two operators already represented in one declared retained coordinate system?

Examples include a trial reduction versus an analytical reference and a spectral
reduction versus an analytical reference. A trial and spectral reduction must not be
compared directly merely because both are `K` by `K`; their retained coordinates must
first be identified or aligned.

For QHO1D, diagonal entries in the analytical number-state coordinates describe
retained energy shifts and off-diagonal entries describe mixing in that declared
coordinate convention. For PIAB1D, comparison to the continuum diagonal reference
aggregates finite-difference spectral discrepancies only after the sampled sine labels
are declared as the retained coordinates.

The comparator does not establish operator convergence, physical adequacy,
identifiability, or uncertainty quantification.
