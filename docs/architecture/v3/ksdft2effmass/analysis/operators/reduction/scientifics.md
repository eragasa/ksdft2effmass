# Scientific interpretation

Orthogonal reduction represents one finite operator on a declared retained subspace.
It does not establish that the retained subspace is physically preferred or complete.

For PIAB1D sampled sine modes, the trial subspace should be invariant under the centered
Dirichlet stencil in exact arithmetic. For QHO1D sampled Hermite modes on a finite grid,
trial leakage is generally nonzero. A numerical spectral subspace is invariant only up
to represented eigensolver arithmetic.

The reduction result does not compare to continuum energies, establish continuum
operator convergence, or select a scalar error metric.
