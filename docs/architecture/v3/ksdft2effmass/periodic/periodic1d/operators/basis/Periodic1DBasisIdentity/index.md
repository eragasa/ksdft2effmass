# `Periodic1DBasisIdentity`

Frozen, slotted one-dimensional periodic basis identity. It fixes
`spatial_dimension == 1` and requires each plane-wave reciprocal index to contain
exactly one integer component. Equality is exact and does not cross dimensional
concrete types.

Source: `python/src/ksdft2effmass/periodic/periodic1d/operators/basis.py`.
Tests: `python/tests/ksdft2effmass/periodic/operators/test__PeriodicBasisIdentity.py`.
