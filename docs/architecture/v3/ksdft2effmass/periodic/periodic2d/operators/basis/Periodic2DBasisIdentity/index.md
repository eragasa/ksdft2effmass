# `Periodic2DBasisIdentity`

Frozen, slotted two-dimensional periodic basis identity. It fixes
`spatial_dimension == 2` and requires each plane-wave reciprocal index to contain
exactly two integer components. Equality is exact and does not cross dimensional
concrete types.

Source: `python/src/ksdft2effmass/periodic/periodic2d/operators/basis.py`.
Tests: `python/tests/ksdft2effmass/periodic/operators/test__PeriodicBasisIdentity.py`.
