# `Periodic3DBasisIdentity`

Frozen, slotted three-dimensional periodic basis identity. It fixes
`spatial_dimension == 3` and requires each plane-wave reciprocal index to contain
exactly three integer components. Equality is exact and does not cross dimensional
concrete types.

Source: `python/src/ksdft2effmass/periodic/periodic3d/operators/basis.py`.
Tests: `python/tests/ksdft2effmass/periodic/operators/test__PeriodicBasisIdentity.py`.
