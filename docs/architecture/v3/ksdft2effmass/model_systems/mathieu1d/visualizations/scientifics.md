# Scientific interpretation

The complete figure presents two declared finite parent representations, sampled bands,
one finite Fourier transform, and explicit range-indexed consequences. The compact
figure reuses authenticated range errors and omitted-block norms only.

The presentation does not establish continuum convergence, continuum isolation,
uncertainty, an optimal hopping range, or material applicability. A sampled finite gap
is not a continuum isolation proof, and connected finite points are not an asymptotic
fit.

Moving the classes into a package changes no result, verification, projection, figure,
or evidence status.
