identity and rational matrices bind the one exact controlled four-state synthetic parent;
alternate labels or coefficients are rejected rather than treated as the same family.
The calculation later selects the lowest ordered
eigenvalue field and records the first-to-second sampled gap, but configuration
construction proves neither isolation nor locality.

radii define attained finite representations. They do not define a continuum limit,
physical localization length, or statistical training/test population.

Threshold fields are prospective decision controls. Consistency fields admit numerical
correlation checks but must never reverse a threshold disposition. Neither category is an
uncertainty estimate or material-accuracy tolerance.

configuration remains a direct typed input like `Piab1dConfiguration`; scientific
actions own the behavior they perform.
