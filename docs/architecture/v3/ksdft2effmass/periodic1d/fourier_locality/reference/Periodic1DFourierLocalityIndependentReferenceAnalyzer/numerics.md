exact bound parent independently, solves dense Hermitian fibers through direct NumPy
operations, and reconstructs complete Fourier coefficients, truncations, and Hermitian
scalar direct fits without calling production actions.

It directly recomputes error maxima and root-mean-square values, omitted norms, Parseval
residuals, design ranks and condition numbers, route defects, decision masks, first and
sustained passage, adjacent-mesh normalized changes, triangle inequalities, the sampled
gap minimizer, and the finite qualification disposition. Exact fields use zero tolerance;
scientific values use the configuration's unit-aware absolute and relative terms.

Projection comparisons convert boolean and optional inventories to explicit finite typed
operands and compare every projection field with the corresponding admitted-result
field. The returned mapping uses deterministic collision-free names so the byte-owning
verifier can split scientific and `visualization_...` components without reflection.
