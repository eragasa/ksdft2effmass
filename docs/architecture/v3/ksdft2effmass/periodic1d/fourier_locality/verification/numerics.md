# Verification numerics

## Exact comparisons

Schema and calculation identities, the bound controlled-parent identity and coefficients,
rational controls, inventory extents, integer orders, exact-rational-derived coordinates,
semantic refinement-channel names, units, shapes, dtype categories, mask values,
optional identifiers, and dispositions compare exactly.

## Mixed comparisons

Energy-valued values satisfy

\[
|x_a-x_e|\le 10^{-12}E_{\mathrm{ref}}
 +10^{-12}\max(|x_a|,|x_e|).
\]

Dimensionless and squared-energy values use corresponding absolute units. Complex values
compare real and imaginary components under the same declared unit scale. Arrays report
maximum defects and complete index coverage.

## Decision consistency

The verifier independently reconstructs gap minimizer role/index/momentum and passage,
per-range route passage, first-passage identifiers, sustained flags, nondominated masks,
near-tie flags, normalized adjacent-mesh changes, and final refinement disposition. It
also checks maximum and root-mean-square triangle inequalities. A tolerance cannot
reconcile opposite sides of an application, gap, or refinement threshold.

## Completeness

Comparison paths cover every leaf in the actual and expected typed mappings. Unknown,
missing, duplicated, or unvisited paths fail the aggregate. The projection comparison is
separate from result reconstruction so an incomplete plotting subset cannot hide a
result mismatch.
