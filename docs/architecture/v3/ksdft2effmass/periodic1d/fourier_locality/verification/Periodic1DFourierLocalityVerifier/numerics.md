# `Periodic1DFourierLocalityVerifier` numerics

The constructor rejects mutable byte arrays, strings, paths, mappings, and already decoded
objects. This guarantees that SHA-256 and typed reconstruction operate on one immutable
subject.

Independent formulas regenerate exact rational mesh rules before binary64 evaluation.
Dense parent fibers, eigensystems, Fourier phase matrices, Hermitian direct-fit designs,
error summaries, masks, passage values, and refinement operands are all reconstructed.

Exact fields compare without tolerance. Numeric fields use named mixed comparisons with
unit-specific absolute terms. Array comparisons retain the maximum defect and its index.
Threshold-side disagreement is an explicit failed comparison.

Comparison construction assigns unique deterministic names to every declared scientific
and projection check. The projection is constructed from the admitted result; its fields
are compared with the corresponding admitted-result fields, while the underlying
scientific channels are separately checked against independent formulas.
