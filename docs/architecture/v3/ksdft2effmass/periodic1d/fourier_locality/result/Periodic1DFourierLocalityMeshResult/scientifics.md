# `Periodic1DFourierLocalityMeshResult` scientific interpretation

A mesh result is one finite representation of the selected lowest ordered eigenvalue
field. Its complete transform is exact only relative to that sampled cyclic
representation and binary64 arithmetic.

The ordinary support table compares deliberate truncation with an independently fitted
route at the same attained supports. Nondominance is local to that finite table; it does
not imply an optimum over uncomputed supports or mesh sizes.

First passage is an application-threshold statement. Sustained passage records whether
all later attained supports retain the statement. Neither establishes continuum
convergence, and adjacent-mesh comparison is kept outside this record so mesh identity
remains explicit.
