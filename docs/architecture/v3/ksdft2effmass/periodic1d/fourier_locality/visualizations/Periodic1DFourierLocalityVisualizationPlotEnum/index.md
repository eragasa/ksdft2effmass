# `Periodic1DFourierLocalityVisualizationPlotEnum`

## Responsibility

Closed enumeration of the two supported native figure identities.

Expected members correspond exactly to:

- `rank1-fourier-locality.png`; and
- `rank1-fourier-route-agreement.png`.

The enumeration prevents arbitrary plot names, hidden figure variants, and rendering of
an unauthenticated subset under an unsupported identifier.

## Public import

```python
from ksdft2effmass.periodic1d.fourier_locality import (
    Periodic1DFourierLocalityVisualizationPlotEnum,
)
```
