# `Periodic1DFourierLocalityVisualizationPlotEnum` numerics

Enumeration values are exact stable wire strings. Parsing rejects unknown strings,
aliases, case variations, numeric values, and booleans.

The complete enum order defines the required rendering inventory. The visualizer returns
one PNG value for each member in that order and rejects duplicate or missing outputs.

The enum performs no numerical calculation. Its relevance to numerical integrity is
inventory closure: no supported figure can be silently skipped or added after projection
authentication.
