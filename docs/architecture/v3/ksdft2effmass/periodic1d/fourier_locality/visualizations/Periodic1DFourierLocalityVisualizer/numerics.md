# `Periodic1DFourierLocalityVisualizer` numerics

Before rendering, the visualizer canonicalizes the supplied projection through the shared
typed serializer and checks its SHA-256 digest against the passing verification. It also
checks the exact closed plot inventory.

Plot actions receive finite arrays with already correlated units and lengths. Any
nonfinite value, nonpositive logarithmic datum, incompatible shape, missing mask, invalid
first-passage marker, or unsupported enum member fails before PNG publication.

The generic renderer uses fixed figure dimensions and supported image metadata. The
visualizer returns encoded values in enum order. Atomic filesystem publication and
overwrite refusal remain responsibilities of the direct render script.
