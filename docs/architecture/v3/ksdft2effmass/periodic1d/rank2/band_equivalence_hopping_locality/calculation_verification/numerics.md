# Numerical contract

Verification begins from built-in immutable bytes. The bytes must decode as a `Periodic1DRank2CalculationRecord` and re-encode identically. `result()` runs four fixed independent routes under installed comparison policy; retained subject bytes cannot enlarge that policy.

Stored admission does not rerun the independent routes. It requires canonical subject admission, exact aggregate digest equality, a passing closed component inventory, and exact nested parent-family digest correlation before returning the record for rendering.
