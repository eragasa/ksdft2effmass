# `CalculationWireEnum`

`CalculationWireEnum` is the closed retained discriminator inventory for momentum-refinement, adaptive-amplitude, and truncation outcomes. It is a regular `Enum`, not a `StrEnum`, so wire strings remain explicit boundary values rather than implicit strings throughout scientific code.
