# `CalculationWireEnum`

`CalculationWireEnum` is the closed retained discriminator inventory for momentum-refinement, adaptive-amplitude, and truncation outcomes. It is a regular `Enum` with family-owned retained-wire mapping rather than the common `StrWireEnum` conversion contract; wire strings remain explicit boundary values throughout scientific code.
