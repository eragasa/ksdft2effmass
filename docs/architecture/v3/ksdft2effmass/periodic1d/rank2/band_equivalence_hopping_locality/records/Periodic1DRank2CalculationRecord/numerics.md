# Numerical contract

Construction requires the exact parent-family analysis type and admitted closed outcomes for the other three channels. Equality of the shared-control key is exact because the values are authored built-in finite controls, not independently rounded observations.

`_mapping()` emits four fixed fields. The parent family uses its dedicated record owner; the other channels use closed variant-specific mappings. `_from_mapping()` rejects inventory mismatch before reconstructing and revalidating the complete aggregate.
