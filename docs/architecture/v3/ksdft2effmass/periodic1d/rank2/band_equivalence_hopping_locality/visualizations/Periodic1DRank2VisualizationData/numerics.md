# Numerical contract

The source identity is a 64-character lowercase SHA-256 digest. For qualified data, all point channels match the amplitude count; correlations lie in `[-1, 1]`; defect, threshold, weight, and power channels are finite and nonnegative. Hopping displacements are unique increasing built-in integers, and both power matrices have matching row and column inventories.

Canonical decoding requires the exact field set and built-in tuple/scalar types.
