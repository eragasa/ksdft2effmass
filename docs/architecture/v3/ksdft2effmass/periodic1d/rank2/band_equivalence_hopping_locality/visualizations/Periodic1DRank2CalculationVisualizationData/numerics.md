# Numerical contract

Both source identities are lowercase SHA-256 digests. Every nonempty channel matrix has its class-declared row count and one column per associated mesh, refinement level, cutoff, or amplitude. Values are finite and nonnegative; inventories are unique and increasing. Empty inventories require empty channel matrices.

Canonical decoding admits the exact field inventory and repeats all shape, type, finiteness, and ordering checks.
