[`Periodic1DCompositeBandAlignmentIndependentReference`](Periodic1DCompositeBandAlignmentIndependentReference/index.md),
its complete request, and the request-bound
[`Periodic1DCompositeBandAlignmentIndependentReferenceAnalyzer`](Periodic1DCompositeBandAlignmentIndependentReferenceAnalyzer/index.md).
