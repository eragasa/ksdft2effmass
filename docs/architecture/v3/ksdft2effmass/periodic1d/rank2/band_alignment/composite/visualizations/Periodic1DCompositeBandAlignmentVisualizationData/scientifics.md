# Scientific contract

The data object is a lossy report view, not a second result schema. It includes the
retained spectrum, separated conversion, interpolation, truncation, and total channels,
complete block norms, omitted-block diagnostics, and selected alignment defects needed
to display the finite control.

Hopping diagnostics partition unchanged Fourier coefficients for measurement. Support
truncation constructs a different represented field by removing exterior coefficients.
Equal range values do not merge these operations.
