# `Periodic1DCompositeBandAlignmentVisualizationData`

The canonical verifier-owned data contain only values consumed by the six figures:
evaluation coordinates and retained spectrum, cyclic-conversion power, interpolation,
truncation, and total Hamiltonian and ordered-spectrum channels, ordinary omitted-block
norms, complete cyclic block norms, and selected alignment diagnostics. Every field is
independently correlated and digest-bound.

The object exposes separate typed views of the common integer ranges:
`hopping_diagnostic_range_inventory` measures unchanged coefficients, whereas
`support_range_inventory` identifies retained-support policies.
