# `Periodic1DCompositeBandAlignmentVerifier`

The byte-owning verifier hashes and admits exact result bytes, derives the visualization projection, invokes the independent reference analyzer, and composes the aggregate. `admit_stored()` recomputes and exact-compares stored aggregate and projection bytes before rendering.
