# `ksdft2effmass.periodic1d.rank2.band_alignment.composite`

## Purpose

This package owns the direct rank-two composite-band alignment and block-locality
vertical slice. It composes an exact four-state parent, lowest-two-state frames, polar
transport, a declared right-unitary attack, and the sibling `rank2/gauge_alignment/`
pointwise and one-global-unitary capability, represented Hamiltonians, complete block
Fourier transforms, symmetric truncations,
independent verification, and authenticated figures.

workflow code. It is distinct from band-equivalence/locality and from M3 admissible-set
policy. The obsolete unranked `periodic1d.composite_band_alignment` source path is not
retained as a compatibility package.
