# `Periodic1DCompositeBandAlignmentDiagnostics`

This record stores the sampled retained/excluded gap, transport overlap and closure phases, frame/projector/operator defects, attack-recovery defect, cross singular values, and applied rank cutoffs. These are finite numerical diagnostics; the record does not label them continuum certificates.
