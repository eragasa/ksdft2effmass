# `Periodic1DCompositeBandAlignmentAnalyzer`

A stateless pure action whose `execute()` method constructs the exact parent, selects and aligns rank-two frames, represents the Hamiltonian, transforms three channels to block hoppings, evaluates seven ranges, and returns the complete typed result. Filesystem, provenance, verification, and rendering effects are outside this class.
