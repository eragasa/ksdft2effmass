# `Periodic1DCompositeBandAlignmentAnalyzer`

A request-bound pure action whose constructor admits the complete immutable configuration
and the explicitly selected Optimization-owned Procrustes solver. Its zero-argument
`execute()` constructs the exact parent, selects and aligns rank-two frames, represents
the Hamiltonian, transforms three channels to block hoppings, evaluates seven ranges,
and returns the complete typed result. Filesystem, provenance, verification, and
rendering effects are outside this class.
