# `ksdft2effmass.periodic1d.admissible_sets`

## Scientific question

For the frozen rank-two composite parent, finite global alignment-angle family, and
bounded two-parameter candidate family, do prespecified spectral and represented-operator
RMS thresholds admit one common witness, or can their sublevel sets be separated at a
declared numerical resolution?

## Status

This package contains the implemented confirmatory M3 source lifecycle. It consumes exact
canonical `Periodic1DCompositeBandAlignmentCalculationResult` bytes and an explicitly
supplied byte-owning composite verifier. It does not import or execute the retired
historical `periodic1d.multiband_alignment` producer.

The package provides:

- immutable typed thresholds and configuration;
- an immutable request binding controls to exact upstream bytes and SHA-256;
- a request-bound analyzer over canonical represented-operator actions;
- typed quadratic, witness, certificate, evaluation, and locality results;
- direct-formula independent reference analysis;
- one exact-byte verifier that also authenticates the upstream result;
- a verifier-derived visualization projection; and
- a closed two-PNG authenticated visualizer.

Historical M2/M3 artifacts and threshold-sensitivity packages remain provenance
references. The provisional implementation has no accepted migration status, retained
successor execution, seal, Formal certificate, material validation, uncertainty
quantification, publication update, or release status.
