# Numerical contract

Visualization data consists only of built-in immutable tuples and a lowercase SHA-256 source identity. Shapes, finiteness, signs, correlation bounds, displacement ordering, family row inventories, refinement-level inventories, and truncation-channel inventories are validated before canonical serialization.

Visualizers require exact verification and data types, passing verification, matching visualization-data digests, positive built-in integer DPI, and exact enum inventories. Rendered values are immutable validated PNG byte objects.
