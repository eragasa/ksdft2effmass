# Numerical contract

The source identity is a lowercase SHA-256 digest. Parent scales and amplitudes are nonempty finite built-in-float tuples. Gap and singular-value vectors match the parent inventory and are nonnegative. Every landscape has one row per parent scale and one column per amplitude; correlations lie in `[-1, 1]`, while thresholds and weights are finite and nonnegative.

Canonical decoding requires the exact field inventory and reuses the same shape and domain validation.
