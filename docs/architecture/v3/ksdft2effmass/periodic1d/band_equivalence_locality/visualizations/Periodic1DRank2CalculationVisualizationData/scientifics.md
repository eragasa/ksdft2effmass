# Scientific contract

The projection preserves momentum, midpoint interpolation, disjoint validation, omitted-power, finite-range error, and interpolation-control channels separately. Each truncation channel is maximized independently over the retained amplitudes; no shared maximizing amplitude is implied.

An empty validation inventory records that no disjoint validation was retained, such as a refinement-level or evaluation-cap stop. It is not a passing validation result. The projection does not rerun an analyzer or verifier and does not establish scientific validity.
