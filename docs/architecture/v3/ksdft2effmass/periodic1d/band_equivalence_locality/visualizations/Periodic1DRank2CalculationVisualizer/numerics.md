# Numerical contract

Construction requires exact aggregate data and verification types, passing verification, a positive built-in integer DPI, and an exact SHA-256 match between canonical data bytes and the verification-bound projection identity. Momentum, midpoint-amplitude, and completed-truncation channels must be present. Disjoint validation may be absent and is rendered as an explicit missing retained channel.

Rendering returns exactly one validated immutable PNG for every aggregate plot enum member.
