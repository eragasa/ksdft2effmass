# Scientific contract

The aggregate record retains one correlated parent family, momentum refinement, adaptive-amplitude refinement, and ordinary-lattice truncation result. It does not calculate, reclassify, interpolate, verify, or combine the scientific error channels. Each nested result remains owned by its scientific module.

Admission requires one shared scientific-control tuple across all four channels and a full-parent family template with `parent_hopping_scale == 1.0`. This prevents unrelated studies from being presented as one calculation.
