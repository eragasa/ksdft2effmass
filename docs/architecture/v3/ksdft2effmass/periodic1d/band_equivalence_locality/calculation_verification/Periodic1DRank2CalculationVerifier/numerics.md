# Numerical contract

The constructor rejects byte-like substitutes and accepts built-in `bytes` only. Canonical admission requires `from_json(subject).to_json() == subject`; parseable noncanonical representations are rejected.

`result()` hashes the exact original bytes, constructs the fixed component tuple, derives the serialization-only aggregate visualization projection, and authenticates its canonical bytes. `admit_stored()` compares the subject, nested family, family-projection, and aggregate-projection identities and rejects a nonpassing aggregate. It does not rerun an independent scientific route.
