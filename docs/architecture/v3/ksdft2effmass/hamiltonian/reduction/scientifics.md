# Scientific interpretation

Spectral reduction represents one finite Hamiltonian on a declared retained state
space. It does not establish that this state space is physically preferred, complete,
or adequate for an intended use.

For a numerical spectral subspace, represented invariance is limited by eigensolver
arithmetic. Reduction does not compare continuum energies, establish discretization
convergence, align independently constructed state spaces, or select an error metric.
Those questions require separate evidence.
