# Scientific interpretation

A finite domain is an ordered numerical carrier. A momentum domain identifies sampled
reduced coordinates owned by a centered uniform mesh. A translation domain identifies a
finite ordered set of integer coordinate vectors.

Neither carrier supplies a continuum limit, integration weight, reciprocal or direct
metric, physical units, convergence status, support decision, or lattice interpretation.
The `sample_role` records intended use only; an evaluation role does not prove that the
samples were withheld from construction.
