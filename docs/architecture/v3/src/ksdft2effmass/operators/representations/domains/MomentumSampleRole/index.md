# `MomentumSampleRole`

**Defined in:** `operators.representations.domains`

The enum declares why a finite momentum mesh is present:

| Member | Meaning |
|---|---|
| `general` | no construction/evaluation role declared |
| `construction` | samples declared for representation construction |
| `evaluation` | samples declared for evaluation |
