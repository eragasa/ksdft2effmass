# `ksdft2effmass.operators.representations.spaces`

## Source

`python/src/ksdft2effmass/operators/representations/spaces.py`

## Responsibility

The module composes the existing `operators.records` metadata owners into one explicit
identity for a finite represented space. It does not replace `StateSpace`, `Basis`,
`Geometry`, or `EnergyReference`.
