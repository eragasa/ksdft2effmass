# Scientific interpretation

A matrix field associates one finite matrix with each retained domain point. Square fields
may represent endomorphisms; rectangular fields may represent maps between different
coordinate dimensions. The semantic subclasses state intended use only.

No class name establishes Hermiticity, projector identities, unitarity, frame isometry,
periodicity, endpoint sewing, Fourier duality, support completeness, or reconstruction
correctness. Those properties require separate analyzers and evidence.
