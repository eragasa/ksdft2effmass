# Scientific interpretation

A `TransformationIdentity` names a directed derivation edge between two complete
representation identities. The kind distinguishes compression, gauge conjugation,
alignment, Fourier conversion, support truncation, and reconstruction. Method and
orientation remain explicit text because kind alone does not determine an algorithm or
adjoint convention.

An edge identity is not evidence that the operation was executed or admissible. Current
role-transition checks are KSD metadata policy, not a theorem about compatible spaces,
meshes, bases, ranks, supports, or Fourier inventories.
