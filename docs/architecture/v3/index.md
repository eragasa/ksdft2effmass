# Architecture v3

## Scope

Architecture v3 documents the maintained source tree from its current implementation and
authoritative scientific specifications. It is a standalone documentation set: pages in
this tree do not depend on earlier architecture-document trees.

The first documentation tranche covers the representation and transformation foundations
introduced at KSD commit `ed9522dd25c33f2473b2a8320f5fafeeb56ece60` together with the
current uncommitted Phase 1 type-contract correction documented from source.

## Status boundary

An architecture page describes implemented software only when it names an existing source
path. Prospective work must be labeled explicitly and must not be presented as an
available import, numerical capability, scientific result, retained evidence, or formal
proof.

This documentation does not authorize Phase 2 implementation, dependency changes,
scientific execution, schema publication, or release activity.
