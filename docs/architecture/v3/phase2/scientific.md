# Phase 2 scientific scope

A representation node would bind two already distinct objects:

- an intrinsic representation identity; and
- the finite matrix field asserted to realize that identity.

The node boundary would require the field carrier to match the identity carrier, the
complete field domain to equal the identity domain, and matrix dimensions to match the
represented-space rank.

Node construction would establish structural consistency only. It would not establish
Hermiticity, projector identities, gauge validity, frame isometry, Fourier correctness,
support completeness, provenance truth, model adequacy, or scientific acceptance.

Derivation history would remain on transformation identities. Gauge-transformed, aligned,
truncated, or reconstructed states would not become mutually exclusive node subclasses.
