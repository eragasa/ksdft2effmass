# First harness simplification round

evidence extraction, durable-role consolidation, maintained execution boundaries,
capability rationalization, and incremental migration. It preserves the current
generic/project-local dependency direction, explicit inputs, retained historical
evidence, human authority, and protected-action boundaries. It does not activate a
proposal or convert a completed bounded slice into acceptance of the larger program.

proposals, and deferrals. Mutable operational detail remains in the
[durable simplification chain](../../.pi/chains/harness-simplification.chain.json)
and its referenced task records; this index does not duplicate that state.
