Sewing
=======

.. currentmodule:: ksdft2effmass.sewing

The sewing package owns explicit reciprocal-endpoint values and keeps other sewing
problems as separate reserved categories.  Identity reciprocal sewing acts in the
ordered ambient basis; it is not automatically an identity in the retained subspace.
