Certifications
==============

Certification records bind one exact scientific proposition to exact endpoint,
producer, verifier, and artifact identities.  They do not establish scientific
validation or human acceptance.

Optional Python-FLINT Arb capability
------------------------------------

Installing the ``certificates`` extra adds the proposition-specific
``ksdft2effmass.certifications.periodic1d.rank1.first_passing_support.arb`` provider.
The provider performs local enclosure and containment computation only.  It does not
run external electronic-structure software or create retained certification evidence.
