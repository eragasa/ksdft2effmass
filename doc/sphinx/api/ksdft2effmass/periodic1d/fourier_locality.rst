Compatible rank-one Fourier locality
=====================================

This finite control asks how the lowest ordered eigenvalue field of an exact
four-state periodic parent behaves under complete cyclic Fourier representation,
ordinary symmetric support truncation, and a direct Hermitian scalar fit.  The
implemented surface owns the exact typed configuration, calculation action, immutable
correlated result records, independent byte-owning verification, and authenticated
visualization projection, authenticated rendering, and direct effect adapters.  No
retained execution has been performed.

All coordinates, coefficients, energies, errors, and dispositions are finite binary64
values under the declared reference-energy convention.  Sampled gaps and adjacent-mesh
changes are finite diagnostics, not global isolation certificates, continuum errors,
uncertainty estimates, or material validation.  Architecture and scientific limits
are documented at
``docs/architecture/v3/ksdft2effmass/periodic1d/fourier_locality/``.
