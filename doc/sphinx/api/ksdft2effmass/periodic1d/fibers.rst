Parent-qualified periodic-1D fiber requests
============================================

.. module:: ksdft2effmass.periodic1d.fibers

The shared request binds each finite Bloch-fiber construction to an exact
:class:`~ksdft2effmass.periodic1d.Periodic1DFourierHamiltonianToyModel` and to
stable parent-model, represented-operator, and finite-state-space identities.
Dimensions, spectra, paths, file names, and digests are not identity substitutes.
