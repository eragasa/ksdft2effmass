Higher-rank periodic-1D alignment
=================================

This API defines the ranks, circuit depths, reciprocal-space meshes, alignment
families, numerical-rank test, and periodic-frame transport results for the
higher-rank study. Hamiltonian production, independent numerical recalculation,
complete verification, figures, retained calculations, and scientific validation
are not yet implemented.
