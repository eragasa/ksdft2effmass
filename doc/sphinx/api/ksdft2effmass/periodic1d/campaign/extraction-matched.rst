Periodic-1D matched defect extraction
=====================================

.. module:: ksdft2effmass.periodic1d.campaign.extraction.matched

The canonical matched-extraction family owns the retained synthetic known-map
campaign contracts, strict input adaptation, compatibility analysis, workflow, and
independent result verification.  Its represented-operator envelope composes the
general :class:`ksdft2effmass.operators.OperatorRecord` through the explicit row-030
metadata contract; it does not maintain a second dense represented-operator owner.

The retained input and result are synthetic campaign evidence.  Agreement demonstrates
bounded software and numerical behavior only.  It does not validate a material,
impurity model, continuum limit, transferability claim, or uncertainty quantification.
