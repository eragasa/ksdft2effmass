ksdft2effmass documentation
===========================

``ksdft2effmass`` is research software for constructing and evaluating reduced
semiconductor Hamiltonians from first-principles Kohn--Sham calculations.

This Sphinx site contains software-facing user guidance, concepts, API
references, verification documentation, and development guidance. Scientific
research, proofs, publications, architecture records, computational records,
and retained calculation provenance remain in their owning repository-first
locations under ``docs/``.
