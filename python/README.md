# ksdft2effmass Python distribution

`ksdft2effmass` is experimental research software for controlled,
provenance-aware reduction of represented Kohn–Sham operators toward lattice
and effective-mass models.

The Python distribution provides immutable records, serialization contracts,
finite-operator and numerical-analysis utilities, workflow and provenance
contracts, and bounded research-model implementations. A successful software or
numerical verification result does not establish physical-model adequacy,
experimental agreement, uncertainty quantification, or transferability.
Production Quantum ESPRESSO, Wannier90, ABINIT, MPI, scheduler, and HPC execution
is outside the ordinary package verification boundary.

The complete source repository, documentation, release claim inventories, and
issue tracker are available at <https://github.com/eragasa/ksdft2effmass>.
Only signed semantic-version GitHub releases are intended to represent reviewed
research-software snapshots; development versions remain provisional.
