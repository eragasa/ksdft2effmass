# Periodic calculation record JSON version 1

This directory owns the closed language-independent wire schema for the minimal
periodic calculation observation extracted from the accepted QEXSD 23.03.10
artifact. The schema preserves source order and native declared units. Runtime
construction additionally enforces cross-field cardinality and reference
relationships that JSON Schema does not express.

A schema-valid record is software-format evidence only. It does not establish
energy alignment, basis or gauge identity, convergence, numerical verification,
scientific validation, uncertainty quantification, or human acceptance.
